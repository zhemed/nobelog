# 侧栏按比例、内容收窄

## Goal

侧栏写死 300px、内容按 68% 增长，屏幕越宽越显得「左小右大」。让侧栏也按比例，并把内容收窄到舒适行宽。

## 改动（全部在 `≥1650` 块内）

```css
:root {
  --sb: clamp(300px, 16.5vw, 360px);              /* 侧栏 */
  --pn: clamp(240px, 11.7vw, 300px);              /* 右栏 */
  --ct: min(1450px, calc((100vw - var(--sb)) * 0.62));  /* 内容 */
  --gp: calc(((100vw - var(--sb)) - var(--ct) - var(--pn)) / 2); /* 两处留白 */
}
```

- 侧栏、`#main-wrapper` 左外边距、`#topbar-wrapper` 左偏移统一用 `--sb`；
- 主栏、页脚宽度用 `--ct`，左偏移用 `--gp`；面包屑左内边距同样用 `--gp`；
- 页脚内层 `footer` 的 `margin-left` 归零，避免与 `--gp` 叠加。
