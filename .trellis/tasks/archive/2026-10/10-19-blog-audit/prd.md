# 博客全面审查

## Goal

对 `nobelog`（Rust 静态博客生成器 + axum 服务 + 现有内容）做一次**只读**审查，
找出真实存在的问题，按严重度分级并给出证据（命令输出、文件:行号、复现步骤）。

## 范围

| 维度 | 关注点 |
| --- | --- |
| 安全与健壮性 | 路径穿越、请求头处理、panic/500 路径、缓存头正确性、压缩边界、并发/热更新竞态 |
| 渲染与内容正确性 | Markdown 输出、HTML 转义、URL 编码、日期时区、TOC/锚点、canonical/RSS/sitemap |
| 构建 · 资源 · 部署 | 两阶段构建、资源哈希与裁剪、打包脚本、工具链/依赖、死代码与 clippy |
| 线上冒烟 | 本机动态服务（127.0.0.1:10086）真实页面：状态码、控制台错误、链接、移动端/暗色 |

## 约束

- **只读**：不改代码/配置/文档，不重启服务，不提交，不推送，不访问未点名主机（本机服务与 `bw` 除外）。
- 允许运行：`cargo fmt --check`、`cargo clippy`、`cargo test`、`nobelog build --out` 到临时目录、`bw` 本机请求。
- 每条结论必须附证据；没验证的猜测标注"未验证"。

## Acceptance Criteria

- [ ] 三个并行审查方向各自给出「结论 + 证据 + 严重度」。
- [ ] 至少一条经过 Lead 亲自抽查复跑的证据。
- [ ] 线上冒烟覆盖：首页、文章页、标签/分类页、归档、about、404、feed.xml、sitemap.xml。
- [ ] 汇总为按 P0/P1/P2/P3 分级的问题清单，明确"现在就要修"的项。

## Notes

- 审查不改代码；修复是另一轮任务（需用户点名授权）。
