# 内容宽度改为按比例（适配 125% 缩放）

## Goal

用户显示器 2560 但系统缩放 125%，实际 CSS 宽度 2048；此前固定 56 的留白在这个宽度下显得局促。改为内容宽度按比例取可用宽的 68%（上限 1450），剩余空间均分给左右两道留白。

## Requirements

- R1 只改两处宽度公式：主栏 `width` 与页脚 `width / max-width / margin-left`。
- R2 主栏：`min(1450px, 68%)`；页脚：`min(1450px, 68%)`，左偏移 `(100% − 内容 − 240) / 2`。
- R3 右栏仍贴屏幕右缘，页脚与内容列对齐。
- R4 其它规则不动。

## 验证结果（2026-11-03）

| 视口 | 内容列 | 左留白 | 中间 | 右缘 | 溢出 |
| --- | --- | --- | --- | --- | --- |
| 2048（用户实际） | [460, 1648] 1189 | 160 | 160 | 0 | 0 |
| 2560 | [585, 2035] 1450 | 285 | 285 | 0 | 0 |

页脚与内容列等宽对齐。`fmt` / `clippy` / `test` 98 全绿。
