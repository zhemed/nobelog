# 锚定左右：侧栏贴左、右栏贴右（内容不动）

## Goal

按用户指令固定两个锚点：左侧栏贴屏幕左缘（x=0，原本如此）、右侧栏贴屏幕右缘（右缘间隔 0）。**中间内容的位置与宽度保持原样不动。**

## 实现

- 右栏：`margin-right: calc(-1 * var(--g))` + 行 `justify-content: space-between`，把它推出到窗口右缘。
- 内容：`flex: 0 0 auto` + `width: calc(100% - var(--g) - 240px)` 锁定，右栏位移时不随之变宽。
- 页脚：宽度同步为 `calc(100% - 240px - var(--g))`，仍与内容列等宽。
- 右栏贴边后与滚动条产生 6px 横向溢出，用 `#main-wrapper { overflow-x: clip }` 裁掉（经用户确认）。
