# 主栏上限放宽到 1320（≥1650）

## Goal

超宽屏下主栏固定 1060px，与右侧栏之间留下约 581px 空白。把 ≥1650px 时主栏上限提到 1320px，右栏继续贴屏幕右缘，空白缩到约 323px。

## Requirements

- R1 只改 `vendor/patches/patch.css`。
- R2 在 `@media (min-width: 1650px)` 内追加 `#main-wrapper .row.flex-grow-1 > main { max-width: 1320px !important; }`。
- R3 其它断点与布局参数不变（左留白公式、右栏贴右、1200–1649 行为）。
- R4 验证截图统一使用 **1264×809**；≥1650 的效果用数值方式核对。

## Acceptance Criteria

- [ ] 1650–1920px 区间主栏宽度随可用空间增长，上限 1320。
- [ ] 1920px：主栏约 1161（容器 1457 − 240 − 56），不再固定 1060。
- [ ] 2559px：主栏 1320，主栏右缘到右栏约 323。
- [ ] 1264px：布局与改动前完全一致（不受 ≥1650 规则影响）。
- [ ] `fmt` / `clippy` / `test` / `build` 全绿。
- [ ] 任务归档并记录 journal，提交带任务锚点。
