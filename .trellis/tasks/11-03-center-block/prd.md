# 内容块整体居中、两侧留白相等

## Goal

超宽屏下内容偏左、右侧空白过大。改为「内容 + 右栏」作为一个整体在侧栏右侧区域水平居中，两侧留白相等。

## Requirements

- R1 只改 `vendor/patches/patch.css`。
- R2 `@media (min-width: 1650px)`：
  - `#main-wrapper > .container`：`width: calc(100% - 112px)`、`max-width: 1457px`、`margin-left/right: auto`；
  - 主栏 `max-width: none`（吃满容器）；
  - 行 `justify-content: flex-start`；
  - `#panel-wrapper { margin-left: 56px }`，宽度仍 240。
- R3 1200–1649 行为不变；1264 视图零变化。
- R4 验证基准：**1920×1080**；另核对 1440、2560。

## Acceptance Criteria

- [ ] 1920：容器 [382, 1457]，左右留白均约 82，主栏 1161，右栏宽 240。
- [ ] 2560：容器 1457 居中，左右留白相等（约 400）。
- [ ] 1440：容器 = (1440−300)−112，margin 56。
- [ ] 1264：与现在逐像素一致。
- [ ] 无横向溢出；`fmt` / `clippy` / `test` / `build` 全绿。
- [ ] 任务归档并记录 journal，提交带任务锚点。

| 1264（回归） | 316, 892 | 596 | 968, 1208 | 56 | 56 |

- 质量：`fmt` 通过、`clippy` 无警告、`test` 98 passed、`build --release --locked` 通过。
